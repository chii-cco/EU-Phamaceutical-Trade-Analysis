# EU-Phamaceutical-Trade-Analysis
Analysis of national import value based on medical supply strategies announced after the COVID-19 pandemic. Coverage period: 2018–2025. Data source: Eurostat (import value).


## Overview
This project examines EU pharmaceutical import
patterns pre- and post Covid between 2018 and 2025.

## Data
- Source: Eurostat
- Frequency: Monthly/EUR
- Period: 2018–2025

## Methods
- Ordinary Least Squares (OLS)
- Regression Discontinuity in Time (RDiT)
- Data visualization using R

## Tools
- R
- tidyverse
- fixest
